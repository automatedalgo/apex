# Folder Organisation

## `core`

Core engine framework, such are market data, orders, trading bots.

## `model`

Classes that model the trading business domain

## `backtest`

Classes related to backtesting, such a tick replay.

## `net`

Networking code.

## `util`

Various utilties, mostly unrelated to trading.

## `venues`

Code to connect to various exchanges, for market-data and order-entry.

## `gx`

Gateway Connector code - used when Apex connects to trading venues via an
intermediate gateway connector.
